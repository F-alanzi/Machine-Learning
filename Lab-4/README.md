# Lab 4 — Machine Learning Data Exploration & Preprocessing

This folder contains **Lab 4** for the Machine Learning course, focusing on *data exploration, quality assessment, and preprocessing* using Python. The main activity is implemented in a Jupyter Notebook that demonstrates how to load, inspect, clean and prepare a dataset for further machine learning tasks.

---

## 🧠 Overview

In this lab, you will learn how to:

1. **Import necessary libraries** for data analysis and visualization (e.g., `pandas`, `numpy`, `seaborn`, `matplotlib`).
2. **Load and preview data** from a CSV file.
3. **Assess data quality** including checking data types and identifying missing values.
4. **Handle missing data** through appropriate strategies like median imputation for numeric columns and fill values for categorical columns.
5. (Optionally) **Visualize and further analyze** the cleaned data to prepare it for machine learning modeling.

This lab is ideal for introducing core steps in a real machine-learning workflow — especially before building models.
