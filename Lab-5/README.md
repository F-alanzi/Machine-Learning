# Lab 5 — ARTI308 Machine Learning Project

This folder contains the content for **Lab 5** of the Machine Learning series in this repository. The focus of this lab is to perform data analysis and build a machine learning workflow using a real dataset.

👉 The main components in this lab are:

- `ARTI308_Lab5.ipynb` — Jupyter Notebook with the full code, analysis, and model training steps.  
- `talabat_enhanced_orders.csv` — Dataset used in this lab for exploration and modelling.

---

## 📋 Lab Overview

In this lab, you will:

1. **Explore and preprocess** the dataset (`talabat_enhanced_orders.csv`), which contains order information.  
2. **Perform data cleaning, visualization, and analysis** to understand feature distributions and relationships.  
3. **Build and evaluate machine learning models** based on relevant features from the dataset.  
4. **Document results** — including model performance and insights — directly within the notebook.

> All work is done interactively in the Jupyter Notebook.
