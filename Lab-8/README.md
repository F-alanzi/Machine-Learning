# 🧪 Lab 8: Machine Learning & Deep Learning

## 📌 Overview
This lab introduces the fundamental concepts of **Machine Learning (ML)** and **Deep Learning (DL)**, along with practical implementation using Python-based frameworks.

The goal is to understand how machines learn from data and how modern tools like TensorFlow and Keras are used to build intelligent systems.

---

## 🎯 Objectives
- Understand the basics of Machine Learning and Deep Learning  
- Differentiate between supervised and unsupervised learning  
- Explore popular ML frameworks (TensorFlow, Keras)  
- Implement simple models using Python  

---

## 🧠 Key Concepts

### 🔹 Machine Learning
Machine Learning is a field of Artificial Intelligence that enables systems to learn from data and improve performance without explicit programming.

**Types of ML:**
- **Supervised Learning**: Learning from labeled data (e.g., classification, regression)
- **Unsupervised Learning**: Finding patterns in unlabeled data (e.g., clustering)

---

### 🔹 Deep Learning
Deep Learning is a subset of ML that uses neural networks with multiple layers to model complex patterns in data.

---

### 🔹 Frameworks Used
- **TensorFlow** – Open-source ML framework by Google  
- **Keras** – High-level API for building neural networks
